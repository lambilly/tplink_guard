# TPLink Guard 手机名单示例 —— 复制为 /config/tplink_guard_phone.txt 后按实际修改
# （原关注名单 tplink_guard_watchlist.txt 已改名为 tplink_guard_phone.txt）
# 每行格式与白名单相同：MAC # 字段1,字段2,字段3（字段用逗号区隔）
# 只有同时存在于白名单中的 MAC 才算「关注终端」（手机名单）。
# 备注字段：姓名,昵称,设备名
#   姓名  —— 显示用真名
#   昵称  —— 来访统计里的称呼（如 妈妈/阿公）
#   设备名—— 可选，仅作说明
# 这三段会被集成解析为实体属性 watchlist，供自动化直接读取，无需硬编码。

AA-BB-CC-DD-EE-01 # 张三,三哥,Phone-A
AA-BB-CC-DD-EE-02 # 李四,小李,Phone-B
